Developer Integration

Embed in 3 Simple Steps

Load the web component bundle, render <qrati-connect>, and bind your theme signal.

event-gallery.component.ts 
// 1. Load element styles & script from CDN or bundle
// Styles: https://cdn.jsdelivr.net/npm/@qratilabs/qrati-connect/element/styles.css
// Script: https://cdn.jsdelivr.net/npm/@qratilabs/qrati-connect/element/web.es.js

// 2. Enable CUSTOM_ELEMENTS_SCHEMA in your Angular component
import { Component, CUSTOM_ELEMENTS_SCHEMA, signal } from '@angular/core';

@Component({
  selector: 'app-event-gallery',
  standalone: true,
  schemas: [CUSTOM_ELEMENTS_SCHEMA],
  template: `
    <qrati-connect
      [attr.organization-id]="orgId"
      [attr.theme]="theme()"
      router="hash"
    ></qrati-connect>
  `,
})
export class EventGalleryComponent {
  readonly orgId = 'your-organization-id';
  readonly theme = signal<'light' | 'dark'>('light');
}
Common Questions

Frequently Asked Questions

Everything you need to know about embedding an event photo gallery in Angular.

How do I embed an event photo gallery in Angular? +
Add CUSTOM_ELEMENTS_SCHEMA to your component's schemas array, load the Qrati Connect element bundle, and render <qrati-connect [attr.organization-id]="orgId" [attr.theme]="themeMode()" router="hash"></qrati-connect>. It provides responsive masonry galleries, lightbox, and photo uploads out of the box.
Can event attendees upload photos directly through the Angular gallery? +
Yes. When media uploads are enabled in your Qrati organization settings, attendees can upload photos and videos directly from mobile or desktop devices with client-side image compression and automatic HEIC conversion.
How does Angular handle web component attribute bindings with Qrati Connect? +
Using Angular's attribute binding syntax like [attr.organization-id]="orgId" and [attr.theme]="themeMode()", Angular seamlessly updates custom element attributes whenever signals change without overhead.
Does the Qrati Connect web component support dark mode? +
Yes. The component accepts a theme attribute ('light' or 'dark'), enabling seamless synchronization with your Angular application's theme signal and system color preferences.
Can I run photo contests and display rankings in the Angular gallery? +
Yes. Qrati Connect supports contest mode, star ratings, emoji reactions, and ranked leaderboards configured directly from your Qrati organization dashboard.
